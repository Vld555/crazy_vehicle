# Решения по баг-репорту

21.11.2026. Решения автора по вопросам разработчика.

| Вопрос | Решение | Проверка |
|---|---|---|
| BR-01. Не указана дата заморозки | База для разработки: ТЗ 0.2 и TC-01…TC-55 из коммита `82d9a73`. Дата фиксации записана при приёмке | Версия и дата указаны в SPEC |
| BR-02. На дробной границе не хватает дров | При ходьбе и беге добавлен относительный допуск `1e-15`. Остаток не уходит ниже нуля | TC-56 проверяет расход впритык. TC-57 проверяет отказ при нехватке |
| BR-03. Слишком большое целое число | В ТЗ явно указано, что число должно преобразовываться в конечный `float`. Поведение из PR сохранено | TC-58 проверяет `ValueError` и сохранение состояния |

BR-01 относится к оформлению ТЗ. BR-02 потребовал уточнения ТЗ, правки кода
и нового теста. BR-03 потребовал уточнения ТЗ и проверки существующего поведения.
