# Безумный транспорт: Ходячая избушка «Бабкин Экспресс»

Учебный проект по дисциплине «Сборка, тестирование и верификация программного продукта».
Стихия — земля. Автор ТЗ и тестов — Харченко Владислав Андреевич.

- [SPEC.md](SPEC.md) — техническое задание.
- [TEST_CASES.md](TEST_CASES.md) — Test Case Specification.
- `walking_hut/` — пакет транспорта (сейчас заглушки с сигнатурами, реализацию пишет разработчик).
- `tests/` — тесты на `unittest`.

## Запуск тестов

```bash
python3 -m unittest discover -v
```
